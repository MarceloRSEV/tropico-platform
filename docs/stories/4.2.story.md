## User Story

**Como** sistema,
**Quero** identificar o perfil (role) do usuário autenticado em todas as operações,
**Para** que admin e client vejam apenas o que é permitido para seu nível de acesso.

---

## Contexto

O role do usuário (`admin` | `client`) é armazenado na tabela `profiles` e incluído no JWT do Supabase via `user_metadata`. A função `auth_user_role()` no banco retorna o role do usuário atual — usada nas RLS policies.

No frontend, o role deve ser acessível via hook React para controle de visibilidade de elementos.

---

## Acceptance Criteria

- [ ] AC1: Hook `useProfile()` retorna `{ id, role, full_name }` do usuário autenticado
- [ ] AC2: Role `admin` vê todas as abas no sidebar: Dashboard, Campanhas, CRM, Análise, Sugestões, Configurações
- [ ] AC3: Role `client` vê apenas: Dashboard, Campanhas, CRM
- [ ] AC4: Acesso direto por URL a `/analysis` ou `/suggestions` por usuário `client` retorna redirect para `/dashboard`
- [ ] AC5: Componente `<AdminOnly>` renderiza filhos somente para role `admin`
- [ ] AC6: Queries ao banco respeitam RLS automaticamente (Supabase client com sessão ativa)
- [ ] AC7: Usuário `client` não vê botões de ação destrutiva (delete lead, aplicar sugestão, etc.)
