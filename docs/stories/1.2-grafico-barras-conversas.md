## 📝 Detalhes Técnicos

### Biblioteca
Usar **Recharts** (já instalado no projeto):
```typescript
import { BarChart, Bar, XAxis, YAxis, CartesianGrid, Tooltip, Legend } from 'recharts';
```

### Dados de Entrada
Do `getMetaDashboardData()`:
```typescript
data.daily[] = {
  date: "2026-09-01",
  spend: 150.50,
  impressions: 5000,
  clicks: 125,
  conversations: 8  // ← USAR ESTE
}
```

### Formato do Gráfico
```
Eixo X: Data (ex: "01", "02", "03"... ou "Seg", "Ter", "Qua"...)
Eixo Y: Conversas (números inteiros)
Cor: Azul (#2563eb)
Altura: ~300px (responsivo)
```
