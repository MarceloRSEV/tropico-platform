# Story 4.3 — Gerenciamento de Usuários (Admin)

**Epic:** 4 — Sistema de Acesso e Permissões
**Status:** Draft
**Prioridade:** Média
**Estimativa:** 3 pontos
**Agente:** @dev (Dex)
**Depende de:** Story 4.1, Story 4.2

---

## User Story

**Como** admin da plataforma,
**Quero** criar, visualizar e desativar usuários,
**Para** controlar quem tem acesso à plataforma Tropico e com qual perfil.

---

## Contexto

Somente o admin gerencia usuários. A criação ocorre via Supabase Admin API (service role) pois requer a criação do usuário no Auth + definição do role no metadata. A página fica em `/settings/users` (rota exclusiva admin).

---

## Acceptance Criteria

- [ ] AC1: Página `/settings/users` listando todos os usuários (nome, e-mail, role, status, data de criação)
- [ ] AC2: Botão "Novo Usuário" abre modal com campos: nome, e-mail, senha temporária, role (admin|client)
- [ ] AC3: Criação de usuário via Supabase Admin API — define role no `user_metadata`
- [ ] AC4: Admin pode alterar o role de um usuário existente
- [ ] AC5: Admin pode desativar um usuário (ban) — usuário não consegue mais logar
- [ ] AC6: Admin não pode desativar a si mesmo
- [ ] AC7: Lista atualiza em tempo real após criação/edição
- [ ] AC8: Página `/settings/users` inacessível para role `client` (redirect)
- [ ] AC9: Feedback visual de sucesso/erro em todas as operações
