## User Story

**Como** admin da plataforma,
**Quero** conectar uma conta Meta Ads e sincronizar dados de campanhas,
**Para** visualizar métricas de performance dos anúncios no dashboard.

---

## Contexto

Integração com Meta Marketing API v20+. O token de acesso do usuário (Long-lived Token) é armazenado criptografado na tabela `ad_accounts`. A sincronização ocorre via Vercel Cron Job a cada 6 horas — busca campanhas e métricas dos últimos 90 dias e salva em `campaign_metrics`.

**Variáveis de ambiente necessárias:**
- `META_APP_ID`
- `META_APP_SECRET`
- `META_ENCRYPTION_KEY` (para pgcrypto)
