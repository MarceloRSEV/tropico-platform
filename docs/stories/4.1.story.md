# Story 4.1 — Autenticação e Gerenciamento de Sessão

**Epic:** 4 — Sistema de Acesso e Permissões
**Status:** Ready for Review
**Prioridade:** Alta
**Estimativa:** 3 pontos
**Agente:** @dev (Dex)

---

## User Story

**Como** usuário da plataforma (admin ou client),
**Quero** fazer login com e-mail e senha de forma segura,
**Para** acessar o dashboard da plataforma Tropico com minhas permissões corretas.

---

## Contexto

Esta é a story base de toda a plataforma. Sem autenticação nada funciona. Utiliza Supabase Auth com JWT. O perfil do usuário (role: admin | client) é criado automaticamente via trigger no banco ao registrar o usuário (`handle_new_user` trigger — migration `20260326000001`).

**Stack:** Next.js 15 App Router + Supabase Auth + middleware de proteção de rotas.

---

## Acceptance Criteria

- [x] AC1: Página de login em `/login` com campos e-mail e senha
- [x] AC2: Autenticação via Supabase Auth (`signInWithPassword`)
- [x] AC3: Após login bem-sucedido, redirecionar para `/dashboard`
- [x] AC4: Sessão persistida via cookie seguro (httpOnly, Supabase SSR)
- [x] AC5: Logout funcional — limpa sessão e redireciona para `/login`
- [x] AC6: Middleware Next.js protege todas as rotas `/dashboard/*` — redireciona para `/login` se não autenticado
- [x] AC7: Usuário sem perfil criado recebe erro amigável (não quebra a app)
- [x] AC8: Loading state visível durante autenticação
- [x] AC9: Mensagem de erro clara para credenciais inválidas (sem expor detalhes técnicos)
